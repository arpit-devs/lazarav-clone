Lazarev Agency Clone

A modern and responsive clone of the Lazarev Agency homepage built using HTML, CSS, JavaScript, and GSAP. This project recreates the smooth scrolling experience, interactive animations, and visually appealing design inspired by the original Lazarev website.

Features

- Smooth scrolling effects
- GSAP-powered animations
- Interactive hover effects
- Modern UI/UX design
- Animated sections and transitions
- Optimized layout for different screen sizes

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)
